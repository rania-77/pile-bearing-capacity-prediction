
# Pile Bearing Capacity Prediction Using Machine Learning

## Project Overview
This project compares three machine learning approaches for predicting the axial bearing capacity of precast concrete driven piles:

- Artificial Neural Network (ANN)
- Genetic Algorithm (GA)
- Hybrid Genetic Algorithm–Artificial Neural Network (GA-ANN)

The project uses real-world pile testing data to investigate the performance of different predictive modeling methods.

## Objectives
- Develop predictive models for pile bearing capacity.
- Compare ANN, GA, and GA-ANN approaches.
- Evaluate model performance using regression metrics.
- Identify the most effective prediction approach.

## Dataset
- 203 field testing records.
- Real-world engineering data related to pile foundation testing.
- Original research data is not publicly provided.

## Methodology
1. Data loading and preprocessing
2. Data normalization
3. ANN model development
4. GA-based regression
5. Hybrid GA-ANN optimization
6. Model evaluation and comparison

## Technologies
- Python
- TensorFlow / Keras
- Scikit-learn
- DEAP
- Pandas and NumPy
- Matplotlib
- Google Colab

## Model Evaluation
Model performance is evaluated using:

- R-squared (R²)
- Root Mean Squared Error (RMSE)
- Mean Absolute Error (MAE)
- Mean Absolute Percentage Error (MAPE)

## Results
The ANN approach demonstrated the best predictive performance among the compared models.
